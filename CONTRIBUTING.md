# Как участвовать в разработке

## Ветки

- `main` — всегда рабочая версия, напрямую не коммитим.
- Новая задача — новая ветка от `main`:
  - `feature/<кратко>` — новая функциональность (`feature/font-size-settings`)
  - `fix/<кратко>` — исправление ошибки
  - `docs/<кратко>` — документация
  - `sync/figma-make-<дата>` — обновление кода из Figma Make ([инструкция](docs/figma-make.md))

## Коммиты

Пишем по-русски, в повелительном наклонении, коротко и по делу:

```
Добавить шаблон «Высокий контраст»
Исправить перенос текста в виджете баланса
```

## Pull request

1. Перед PR проверьте: `pnpm typecheck && pnpm build`.
2. Заполните шаблон PR: что сделано, скриншоты, как проверить.
3. Для изменений интерфейса — проверьте клавиатурную навигацию и контраст.
4. Нужен хотя бы один аппрув от участника команды.

## Доступность — обязательна

Проект про доступность, поэтому каждое изменение UI проверяем на:

- навигацию с клавиатуры (Tab / Shift+Tab / Enter / Esc);
- контраст текста не ниже 4.5:1 (WCAG AA);
- размер целей нажатия не меньше 44×44 px;
- подписи (`aria-label`) у иконок-кнопок;
- работу с `prefers-reduced-motion`.
