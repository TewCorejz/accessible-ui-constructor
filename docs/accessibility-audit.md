|---|---|---|

## Проход «как скринридер» (24.11.2026)

Сценарий «собрать и сохранить интерфейс» пройден только с клавиатуры; на каждой остановке Tab записано, что получает скринридер из дерева доступности Chrome (роль, имя, состояние, описание), и что звучит в live-регионах.

Работает: ссылка «Перейти к содержимому» первой; все 38 остановок на экране «Создать» с ролью и понятным именем; состояния «нажато» у образцов цвета и «Режима расстановки», «развёрнуто» у шторки шаблонов; ползунок «14 пикселей»; после «Добавить виджет» фокус переходит в панель; перестановка озвучивается («левая колонка», «перемещён на позицию 3 из 4»); «Интерфейс сохранён» объявляется.

Исправлено:

| Было (что слышал пользователь) | Стало |
|---|---|
| «Строка выбора названия интерфейса, поле» | «Название интерфейса, поле» |
| «Зелёный, кнопка, нажата, Зелёный» — имя повторялось описанием | «Зелёный, кнопка, нажата» |
| Два поля «Свой цвет» — не различить | «Свой цвет — основной цвет» / «— дополнительный цвет» |
| На каждой кнопке перемещения — инструкция из ~45 слов | Короткая: «Пробел — взять. Стрелки вверх и вниз — позиция, влево и вправо — колонка. Пробел — положить, Escape — отмена.» |
| «Виджет «Баланс», позиция 1» | «…позиция 1 из 3» |
| «Быстрая оплата Важные платежи в один шаг» — слитно | Пауза между названием и описанием |
| «Шаблоны 4» | «Шаблоны, 4» |
| «Удобно каждому» — заголовок h3 перед h1 страницы | Обычный текст; порядок заголовков h1 → h2 → h3 |
